# Rakhi Mahato — Developer Portfolio

A responsive, dark-themed one-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and project details
- `style.css` — layout, colors, responsive styles, and visual effects
- `script.js` — mobile navigation toggle

## Before publishing (important)
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real professional email.
2. Replace the LinkedIn link (`https://www.linkedin.com/`) with your actual profile URL, or remove that button if you do not want to share LinkedIn.
3. Check that every skill listed reflects what you can discuss honestly in an interview.
4. Add the exact public GitHub repository links for Smart Ambulance and InterviewForge where available. Current links for those projects point to your GitHub profile because their exact repository URLs were not confirmed here.
5. Add your college/institution name and study dates if you want them included. Do not publish any detail you do not want to share.
6. Open the website on a phone and desktop, and test every link.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with Netlify (quickest)
1. Visit https://app.netlify.com/drop
2. Sign in or create a Netlify account if prompted.
3. Drag the entire `rakhi-portfolio` folder (or upload the ZIP after extracting it) into the deploy area. If the upload interface accepts only a folder, extract the ZIP first and drag the folder.
4. Wait for deployment and copy the public URL Netlify provides.
5. Open that URL in a private/incognito browser window to verify it works.

## Alternative: GitHub Pages
1. Create a new public repository named `rakhi-portfolio` on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to Settings → Pages.
4. Under build/deployment, choose deploy from a branch, select `main` and `/ (root)`, then save.
5. Wait for the Pages URL to appear and test it.
